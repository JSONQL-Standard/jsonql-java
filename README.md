# jsonql-java

A Java library to parse and validate **JSONQL v1.0** queries against schemas.

## Installation

Add the following dependency to your `pom.xml`:

```xml
<dependency>
    <groupId>org.jsonql</groupId>
    <artifactId>jsonql-java</artifactId>
    <version>1.0-SNAPSHOT</version>
</dependency>
```

## Usage

```java
import org.jsonql.JSONQLParser;

public class Main {
    public static void main(String[] args) {
        JSONQLParser parser = new JSONQLParser();
        // TODO: Implement usage
    }
}
```
